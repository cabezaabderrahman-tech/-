# Low-Token Project Rules

1. 先搜索/定位，再读取文件；禁止无必要读取整个仓库或整个资料库。
2. 只加载当前任务所需的最少上下文。
3. 已经确认的项目背景写入简短摘要，后续优先读取摘要而不是重复读取原始材料。
4. 修改代码或文档时优先局部修改，不全文重写。
5. 自动测试/修复最多 2 轮；超过后停止并列出剩余问题。
6. 不输出长篇思考过程；输出结果、关键依据、必要说明即可。
7. 大文件优先按页、章节、函数、模块分段处理。
8. 数据研究优先权威来源；不要为了“多来源”无意义重复搜索相同内容。
9. 每个阶段结束更新：目标、已完成、关键决定、待办、重要文件位置。
10. 能用脚本/公式完成的批量计算，不让语言模型逐行计算。
